# 📚 Scribe

> **An AI-powered reading companion** that makes books come alive — with reflections, summaries, and story-aware interactions that feel as immersive as watching a great TV show.

---

## 🌟 Overview

**Scribe** is a Flutter-based mobile app built around the idea that reading should be interactive, personal, and deeply engaging.

Readers can upload or import books, read them seamlessly, and interact with an **AI companion** that adds depth and context — offering:
- “Previously on…” chapter recaps  
- Reflective and moral questions  
- Character and theme insights  
- Contextual summaries  
- Reading-mood adaptive UI (light/dark or emotion-based)

Scribe transforms passive reading into a **dialogue between the reader, the story, and the AI**.

---

## 🧠 Core Features

| Feature | Description |
|----------|--------------|
| 📖 **Smart Reading Experience** | Clean, distraction-free reading interface optimized for long sessions. |
| 💬 **AI Companion** | Context-aware AI that reacts to the text — prompting questions, dilemmas, or summaries. |
| 🎭 **Dynamic GenUI (Generative UI)** | Layouts and panels are generated based on context — e.g. “AI Thoughts”, “Theme Reflections”, or “Previously…” appear only when relevant. |
| ☁️ **Supabase Backend** | Handles authentication, book uploads, and syncing reading progress across devices. |
| 🔄 **Offline-First Architecture** | Local caching ensures a smooth reading experience even without internet connectivity. |
| 🔔 **Interactive Notifications** | The AI can send reading prompts or chapter-summary reminders. |
| 🌗 **Adaptive Themes** | Automatic mood-based theming — light, dark, or context-driven (e.g. warm tones for romance scenes). |
